# Braydr — デザインシステム

Braydr の macOS アプリをどう見せるかを定める。

機能、条件、データは `product-spec.md` に書く。この文書は見た目と文言だけを扱う。
見た目を変えても変わらないことは `product-spec.md`、変わることはこの文書に置く。

## 1. 原則

1. **レイアウトが説明する。** 配置・形・面で意味が伝わるなら、ラベルや説明文を置かない。
2. **人を描かない。** 利用者は 1 人。名前もアイコンも持たない。発言者は色の反転で示す。
3. **いま必要な動線だけを見せる。** 機能は階層に収め、文脈の中で現れるようにする。
4. **色は意味にだけ使う。** 面と文字は無彩色で組む。色は未読、未解決、停止と、確定や削除の操作に限る。
5. **静かな状態は静かに。** 正常・完了は目立たせない。未読・未解決・例外だけが浮かぶ。

## 2. 基礎

| `tint` | `#F4F4F1` | コードブロック、ホバー、解決済みの導線 |

| `ink-3` | `#8E8E92` | 時刻、件数、補助のアイコン |

### 文字

| 用途 | フォント | サイズ / 字重 |
| --- | --- | --- |
| 大見出し（チャンネル名の入力） | IBM Plex Sans JP | 24 / 500 |
| 検索の入力 | IBM Plex Sans JP | 16 / 400 |
| ダイアログの見出し | IBM Plex Sans JP | 15 / 600 |
| シートの見出し | IBM Plex Sans JP | 14 / 600 |
| 本文 | IBM Plex Sans JP | 14 / 400、行高 1.65 |
| UI | IBM Plex Sans JP | 13 / 400・500 |
| 補助（時刻・件数） | IBM Plex Sans JP | 12 / 400 |
| コード | IBM Plex Mono | 12.5 / 400、行高 1.6 |

字重は 400 / 500 / 600 の 3 段に限る。

### 形と余白

- 余白は 4 の倍数を基本にする。
- 角丸: ボタンと行 7、導線とコードと選択欄 8、シート 10、メニュー 10、投稿欄 12、バブル 14、
  パネルとダイアログ 14。
- 影はダイアログ、メニュー、パネルだけ。シートは細い線で分ける。
- カードで包まない。面が要るのはシート、バブル、コード、投稿欄、メニュー、パネル、導線だけ。

### アイコン

Lucide を線幅の既定値で使う。サイズは 16 を基本に、文字に添えるものは 14 にする。
文字が要る操作は文字を優先する。

## 3. ウィンドウ

```text
┌──────────────────────────────────────────────────────────┐
│ ● ● ●       ⊟ ┌──────────────────────┐ ┌───────────────┐ │
│               │ ログイン修正 ⌄ 未解決 │ │       解決 ×  │ │  ← y = 30
│ チャンネル  + │                      │ │               │ │
│               │ ┌──────────┐         │ │ ┌───────┐     │ │
│               │ │ ユーザー  │         │ │ │       │     │ │
│               │ エージェント本文      │ │ 返信          │ │
│               │ ┌──────────────────┐ │ │ ┌───────────┐ │ │
│               │ │ 投稿欄           │ │ │ │ 投稿欄    │ │ │
│               └─┴──────────────────┴─┘ └─┴───────────┴─┘ │
└──────────────────────────────────────────────────────────┘
```

| 面 | 役割 | 寸法 |
| --- | --- | --- |
| ウィンドウ | 基調の 1 枚。タイトルバーを持たない | 初回は 1440 × 900、角丸 12 |
| サイドバー | チャンネルの移動。ウィンドウに直接置く | 初期幅 240。180〜400 で変えられる |
| メインシート | タイムライン | 残りの幅。本文カラムは最大 720、中央寄せ |
| 右シート | スレッド | 初期幅 416。320〜720 で変えられる |

- シートはウィンドウの外周とシート同士の間を 8 空ける。
- サイドバーの右端と、シート同士の間を横にドラッグすると幅が変わる。つかむ場所はホバーで `hairline` の面になり、ダブルクリックで初期幅に戻る。幅は覚え、次に開くときに戻す。
- メインシートは幅 360 を保つ。ウィンドウが狭くなると右シート、サイドバーの順に最小幅まで縮み、広がると選んだ幅に戻る。
- タイトルバーの代わりに、サイドバーの上部とシートのヘッダーで、ドラッグの移動とダブルクリックの最大化を受ける。
- 位置、サイズ、ディスプレイ、最大化の状態を覚え、次に開くときに戻す。ディスプレイがなくなっていたら、今の画面に収めて中央に開く。
- 左から右へ進むほど詳細になる。一時的に見るものはパネル、読み込むものは右シートに置く。
- **信号機の軸を全体で共有する。** 信号機の中心 y = 30 に、サイドバーのボタン、チャンネル名、
  右シートのヘッダーをそろえる。シートの上端は y = 8、ヘッダーは高さ 44。
- サイドバーを畳むと、シートが横に広がり、信号機はヘッダーの中に収まる。
  信号機の位置は動かさず、見出しがその右に移る。

## 4. 部品

### サイドバー

一番上の `未読` は、未読の一覧を開く行。`inbox` のアイコンと文字に、未読があれば右端に `unread` の点を付ける。

チャンネルの行は高さ 30。次の順に並べる。

```text
● 決済APIリファクタ                2
```

- 先頭の記号: 生存は `ink-4` の点、未読は `unread` の点、停止と確認待ちは `warn` の点（未読と同じ形で色だけ変える）。
- 重なったときは停止と確認待ちを優先する。
- 右端の数字: 未解決スレッド数を `ink-3` の 12px で右寄せする。0 件なら出さない。
- 選択は `selected` の面で示す。
- ドラッグで並び替える。持っている間はチャンネル名を浮かせて示し、落とす先の行の上か下に `accent` の線を引く。

### チャンネルのヘッダー

- 左にチャンネル名とメニューの印。停止中と確認待ちはその右に `warn` の点と `停止中` / `確認待ち` を出す。
- 右に `未解決 N` と検索アイコンをこの順に置く。どちらも背景色と状態色を持たない。`未解決 N` は 0 件なら出さない。未解決スレッドに未読があれば、先頭に `unread` の点を付ける。

### チャンネル名のメニュー

```text
✎ 名前を変更
─────────────
hc attach t7      ⧉
↺ 新しいセッションを開始
─────────────
🗑 チャンネルを削除
```

停止中は終了理由もここに出す。

### メッセージ

名前もアバターも使わず、色の反転で発言者を示す。どちらも左端にそろえ、1 本の軸で読む。

| 発言者 | 形 |
| --- | --- |
| ユーザー | バブル。`ink` の塗りに白文字。短い文では文字に合わせて縮む |
| エージェント | 全幅の本文。枠なし。文書のように読む |

各メッセージの直下に時刻を置き、その右に導線と操作を並べる。時刻は今日なら `14:20`、今年なら
`10/31 14:20`、それより前なら年も付ける。

```text
14:20  [ 4件の返信  15:12 ● ]  [⧉]
14:58  [ ↩ スレッドで返信 ]  [⧉]
```

コピーを押すと、アイコンが 1.5 秒間チェックに変わる。メニューとバナーの attach のコマンドも同じ。

各メッセージは左右 10、上下 7 の余白を持つ面で、ホバーと検索の強調はこの面で受ける。文字の位置はこの余白の
分だけリストの余白を減らしてそろえる。

`スレッドで返信` とコピーはホバー時だけ出す。`スレッドで返信` は導線と同じ形で同じ位置に置く。

### スレッド導線

導線は高さ 26 の面を持つボタンとする。中の時刻は最終返信の時刻で、面で囲んで投稿時刻と区別する。

| 状態 | 面 | `N件の返信` | 時刻 |
| --- | --- | --- | --- |
| 未解決 | `accent-tint` | `accent` | `accent-soft` |
| 解決済み | `tint` | `ink` | `ink-3` |

未読なら末尾に `unread` の点を付ける。開いているスレッドの導線も同じ表示にする。

### スクロールバー

タイムライン、右シート、パネルのスクロールできる面には、スクロールバーを必ず表示する。

### 未読の区切り

文字を中央に置き、両側に線を引く。線は `unread`、文字は `unread-text`。上下の余白は見た目でそろえる。

### 投稿欄

角丸 12 の枠に入力と丸い送信ボタンを置く。フォーカス中は枠を `accent` にする。
送信できるときボタンを `ink` に、それ以外は `tint` にする。

### 右シート

- ヘッダーの右に操作と `×` を置く。戻る操作は持たない。
- 親メッセージを先頭に置き、返信と一緒にスクロールする。区切り線は引かず、メッセージ同士と同じ間隔で続ける。親がエージェントの発言なら全幅の本文で表示する。
- 未解決なら `解決` を出す。解決済みなら左に `解決済み`、右に `再開` を出す。
- スレッドの下書きでは、親と投稿欄と `×` だけを出す。

### 解決状態の履歴

返信の間に、左端にそろえた 1 行で静かに表示する。時刻は同じ行に置く。

```text
✓ エージェントが解決  14:02
↺ あなたが再開  13:52
```

### パネル

未解決スレッドの一覧、未読の一覧、検索に使う。背景は暗くせず、Esc か外側のクリックで閉じる。

| | 未解決スレッドの一覧 | 検索 |
| --- | --- | --- |
| 位置 | `未解決 N` の真下 | 画面上部の中央 |
| 幅 | 408 | 600 |
| 上部 | なし | 入力欄と件数、細い線 |
| 行 | 親メッセージ（2 行まで）と、下に件数、時刻、未読の点 | 1 行の抜粋と右端の時刻 |

未読の一覧は幅 408 で、サイドバーの右、`未読` の行と同じ高さに置く。行は最初の未読メッセージ（2 行まで）と、下にチャンネル名、スレッドなら親メッセージ（1 行で切り詰める）、時刻。

- 行の間に線は引かず、余白で分ける。文字色は状態で変えない。
- 検索の一致箇所は `match` の面で示す。選んだメッセージも一時的に `match` の面で示す。

### ダイアログ

幅 320 を基本に、中央に置き、背景を薄く暗くする。確定ボタンは `accent` の面に白文字。

- **新しいセッションの開始:** 説明文、作業ディレクトリ、起動コマンド、プロンプト、`キャンセル`、`開始`。幅は 440。
- **チャンネル名の変更:** 入力欄、`キャンセル`、`保存`。
- **チャンネルの削除:** メニューの項目はアイコンも文字も `warn`。ダイアログは説明文、`キャンセル`、`warn` の `削除`。

作業ディレクトリはフォルダのアイコンとパスで示し、押すと macOS のフォルダ選択パネルを開く。
起動コマンドとプロンプトは等幅の複数行入力で、ラベルを付けない。

### 設定

アプリメニュー（⌘,）から開く別ウィンドウ。信号機のみのタイトルバーを持ち、幅は 560。
`起動コマンド`、`プロンプト`、`返信がないエージェントへの再通知` を縦に並べる。最後の値は `5 分ごと` のように示す。ここは項目の意味が読み取れないので、ラベルを付ける。

### チャンネル作成

シートの中央に幅 480 のフォームを置く。大見出しの名前入力、作業ディレクトリ、起動コマンド、プロンプトを
縦に並べ、右下に `作成` を置く。
`作成` は `accent` の面に白文字。

## 5. 状態

| 状況 | 表現 |
| --- | --- |
| チャンネルがない | チャンネル作成のフォームを出す。Esc では閉じない |
| 空のチャンネル | 投稿欄だけをシートの中央に置く。投稿すると下端へ移る |
| 検索結果がない | 入力欄だけを残し、件数を `0件` にする |
| 未解決スレッドがない | `未解決 N` を出さない。一覧を開いている間に 0 件になったら閉じる |
| 投稿失敗 | 送信ボタンを `warn` の再試行アイコンに変える |
| 停止 | 投稿欄の直上に `warn-tint` のバナーと、`ink` の `新しいセッションを開始` を置く |
| 未起動 | 停止と同じバナーに `再試行` を置く |
| 起動中 | 生存と同じ表示にする |
| 実行中 | チャンネル名の右に `ink-3` の 12px で、回転するスピナー（`loader-circle`）と `実行中` |
| 確認待ち | サイドバーとヘッダーを停止と同じ `warn` の点にし、ヘッダーに `確認待ち` と出す。投稿欄の直上に停止と同じ `warn-tint` のバナーと `エージェントが確認を待っています`、attach のコマンドとコピーを置く |

## 6. 文言

- 名詞か短い動詞で書く。「〜できます」「〜してください」の説明文を置かない。
- 「再起動」「再作成」は使わない。文脈が復元されるように読めるため、`新しいセッションを開始` と書く。
- 未解決に戻す操作は `再開` と書く。
- 「督促」は使わない。`再通知` と書く。
- プレースホルダーは `メッセージ` と `返信` の 2 語を基本にする。
- 注意文は関係する操作の直上に置く。

| 場面 | 文言 |
| --- | --- |
| 解決済みのスレッドへの投稿 | `投稿すると再開します` |
| 再開した直後 | `エージェントへの依頼は投稿で伝わります` |
| 停止中 | `セッションが停止しています` |
| 新しいセッションの開始（生存中） | `進行中の作業は中断され、エージェントの作業コンテキストは引き継がれません。` |
| 新しいセッションの開始（停止中） | `エージェントの作業コンテキストは引き継がれません。` |

## 7. アプリアイコン

白と `accent` の吹き出しを積んで頭文字の B にし、`ink` の地に置く。白がメイン、青がスレッドを表す。
1024 の枠に 824、角丸 185 の面を置く macOS の寸法に従う。元は Pencil のファイルの `アプリアイコン` で、
書き出しは `design/exports/app-icon.png` と `crates/braydr-app/assets/app/AppIcon.icns`。
