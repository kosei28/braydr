# Braydr — 手動の確認表

自動テストでは確かめられないこと。リリース前と GPUI の更新時に行う。`.app` から起動する。

| 項目 | 手順 | 期待 |
| --- | --- | --- |
| Finder からの起動 | `.app` を Finder で開き、`claude` の既定値でチャンネルを作る | 停止にならず、エージェントが起動する |
| 信頼の確認 | 信頼していないディレクトリでチャンネルを作り、投稿する | セッションは終了しない。`hc attach` で承認すると投稿を読んで動き出す |
| ウィンドウの移動 | サイドバー上部、シートのヘッダーをドラッグ / ダブルクリック | 移動する / 最大化が切り替わる（システム設定の動作に従う） |
| ウィンドウの記憶 | 移動とサイズ変更、最大化をして開き直す / ディスプレイを外して開く | 同じ位置とサイズで開く / 残ったディスプレイの中央に開く |
| パネルの幅 | サイドバーの右端とシートの間をドラッグする / ダブルクリックする / ウィンドウ外で離す / 開き直す | 幅が追従する / 初期幅に戻る / 戻ってきても追従しない / 同じ幅で開く |
| 信号機 | 開く / サイドバーを畳む / 全画面 | 信号機とヘッダーの中心がそろう。畳むと見出しが信号機の右に移る |
| IME | 投稿欄で日本語を変換し、Enter で確定する | 確定だけが起きて投稿されない。⌘Enter で投稿する |
| IME（フォーカスの移動） | スレッドを開き、メインの投稿欄で変換中に返信欄を押して入力する | 変換中の文字は元の欄に確定して残り、返信欄では普通に入力できる |
| IME（下書き） | 変換中のまま別のチャンネルを選び、戻る。スレッドの返信欄でも同じことをする | 書きかけが戻り、変換中だった文字が消えたり二重になったりしない |
| IME（部分変換） | 複数の文節を変換し、左右キーで文節を移る | 変換対象の文節が選択色になる |
| IME（検索と名前） | 検索、チャンネル名、ダイアログの入力欄で変換する | 確定で何も実行されない |
| 通知の表示 | 別のアプリを前面にしてエージェントに投稿させる | チャンネル名と本文の先頭で通知が出る |
| 通知の置き換え | 同じタイムラインに続けて投稿させる | 通知は 1 件のまま新しくなる |
| 通知の取り消し | 通知を押さずに該当タイムラインを開く / 最下部まで読む | 通知が消える |
| 通知の遷移 | 通知を押す（メイン、スレッド） | 前面に出て、そのタイムラインが開く |
| 既読 | 未読が多いタイムラインを開いて少しスクロールして閉じる | 見たところまで既読。次回は続きから開く |
| 既読（離す場所） | スクロールバーやパネルの端を押したまま、ウィンドウの外やパネルの上で離し、新着を待つ | クリックし直さなくても、最下部の新着が既読になる |
| 既読（ドラッグ） | スクロールバーで一気に下げて途中まで戻してから離す | 通過しただけの行は既読にならない |
| スクロールバー | タイムライン、右シート、パネル | 常に見える |
| 停止 | セッションを `hc` で終了する | 数秒以内にサイドバー、ヘッダー、バナーが停止になる |
| 新しいセッション | 値を変えて開始する | チャンネルに保存され、次回の初期値になる |
| 再通知 | 設定で 1 分にして未返信のまま待つ | セッションに `[braydr] nudge` が届く |
| 実行中 | エージェントに長めの作業を頼む | 作業中はチャンネル名の右に回るスピナーと `実行中` が出て、終わると消える |
| 並び替え | チャンネルを上下にドラッグする | 線の位置に入り、投稿や再起動の後も順序が残る |
| 未読の一覧 | 別のチャンネルとスレッドに未読がある状態でサイドバーの `未読` を押す | 両方が新しい順に並び、選ぶとそこが開いて一覧が閉じる |
| チャンネル削除 | メニューから削除して確定する | 確認の後に消え、セッションが終了して、先頭のチャンネルが開く。最後の 1 つなら作成フォームが開く |
| 確認待ち | エージェントに許可が必要な操作を頼む | サイドバーとヘッダーに `warn` の点、ヘッダーに `確認待ち`、バナーとコピーできるコマンドが出る。再通知は届かない |
| 再通知（止まってから） | 設定で 1 分にして、作業中に未返信のまま待つ | 作業中は届かず、止まって 1 分後に届く |
| 開いているスレッド | スレッドを開く / 別のスレッドを開く / 閉じる | 親メッセージの左に青い縦線が出る / 線が移る / 線が消える |
| 親メッセージまでのスクロール | スレッドを、未解決の一覧、未読の一覧、通知、検索から開く。親が見えているときも試す。別のチャンネルから戻る | メインのタイムラインが、親の先頭が上端に来る位置まですぐに移る。戻ったときは元の位置が一瞬も見えない |
| 投稿欄の行 | スレッドを開き、スクロールして最下部まで読む。返信欄で改行を重ねる | 最後のメッセージが隠れず、最下部を表示したまま |
| 狭いウィンドウ | ウィンドウを最小まで狭める。途中でスレッドを開き、サイドバーのボタンを押す。停止と確認待ちのチャンネルで、メニュー、一覧、検索、ダイアログを開く | 400 × 480 より小さくならない。916 未満（畳めば 744 未満）でスレッドがメインを覆い、720 未満でサイドバーがドロワーになる。バナーは折り返し、パネルとダイアログは左右に余白を残して収まる |
| コードのコピー | エージェントのメッセージのコードブロックにポインタを載せ、右上のボタンを押す。ポインタを外す | ボタンはホバー中だけ出て、押すとチェックに変わり、コードだけがコピーされる |
| 文字の選択 | ユーザーのメッセージの一部をドラッグする / ユーザーとエージェントのメッセージをまたいでドラッグし、⌘C で貼り付ける | 選んだ部分が白の薄い色になる / 読む順でコピーされ、ユーザーの文は打ったとおり（`**` などもそのまま）になる |
| 見た目 | `design/braydr.pen` の 21 画面と比べる | 差があれば直すか、文書を更新する |
