# Braydr — 手動の確認表

自動テストでは確かめられないこと。リリース前と GPUI の更新時に行う。`.app` から起動する。

| 項目 | 手順 | 期待 |
| --- | --- | --- |
| 信号機 | 開く / サイドバーを畳む / 全画面 | 信号機とヘッダーの中心がそろう。畳むと見出しが信号機の右に移る |
| IME | 投稿欄で日本語を変換し、Enter で確定する | 確定だけが起きて投稿されない。⌘Enter で投稿する |
| IME（検索と名前） | 検索、チャンネル名、ダイアログの入力欄で変換する | 確定で何も実行されない |
| 通知の表示 | 別のアプリを前面にしてエージェントに投稿させる | チャンネル名と本文の先頭で通知が出る |
| 通知の置き換え | 同じタイムラインに続けて投稿させる | 通知は 1 件のまま新しくなる |
| 通知の取り消し | 通知を押さずに該当タイムラインを開く / 最下部まで読む | 通知が消える |
| 通知の遷移 | 通知を押す（メイン、スレッド） | 前面に出て、そのタイムラインが開く |
| 既読 | 未読が多いタイムラインを開いて少しスクロールして閉じる | 見たところまで既読。次回は続きから開く |
| 既読（ドラッグ） | スクロールバーで一気に下げて途中まで戻してから離す | 通過しただけの行は既読にならない |
| スクロールバー | タイムライン、右シート、パネル | 常に見える |
| 停止 | セッションを `hc` で終了する | 数秒以内にサイドバー、ヘッダー、バナーが停止になる |
| 新しいセッション | 値を変えて開始する | チャンネルに保存され、次回の初期値になる |
| 再通知 | 設定で 1 分にして未返信のまま待つ | セッションに `[braydr] nudge` が届く |
| 応答なし | エージェントが動かない起動コマンドで作る | 60 秒でバナーとコピーできるコマンドが出る |
| 見た目 | `design/braydr.pen` の 16 画面と比べる | 差があれば直すか、文書を更新する |
